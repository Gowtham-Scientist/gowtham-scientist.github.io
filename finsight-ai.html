01 / ENGINEERING APPROACH

Built for traceability, not just fluent answers.

Financial-document research needs more than retrieval and generation. FinSight connects each answer to source evidence, checks numerical claims, records workflow state, and makes review an explicit release control.

01 / EVIDENCE

Citation-complete retrieval

Every retrieval result retains filing, section, date, rank, score, and source identity. Application-rendered citations reject evidence IDs the model did not receive.

02 / VALIDATION

Exact financial arithmetic

SEC company facts are stored as exact decimals. Failed calculations are excluded from answer text and escalated for review instead of being presented as facts.

03 / CONTROL

Human approval by design

The LangGraph workflow pauses at a mandatory review interrupt and records attributable approve-or-reject decisions before an answer can be released.

02 / ARCHITECTURE

One system, from filing to reviewed response.

The implementation covers the complete investigation path, with evaluation, observability, and deployment controls treated as first-class engineering work.

Source + provenance

Policy-compliant SEC ingestion

Identifiable user agent, bounded retries, request pacing, document hashes, stable sections, token offsets, and idempotent persistence.

Retrieval

Vector and keyword evidence channels

pgvector cosine search and PostgreSQL full-text candidates are combined with weighted reciprocal-rank fusion and issuer-aware filters.

Orchestration

Durable LangGraph investigations

Typed workflow state, PostgreSQL checkpoints, MCP evidence tools, and resume behavior that does not repeat completed model execution.

Safety + evaluation

Grounding, guardrails, and reproducible experiments

Structured outputs, citation and numerical validation, versioned benchmarks, paired statistical analysis, assignment controls, and preregistered outcomes.

Delivery

API, analyst workspace, and telemetry

FastAPI services, a Next.js analyst interface, bearer authentication, OpenTelemetry spans and metrics, and credential-redacted structured logs.

03 / STACK + DEPLOYMENT

Production-oriented from code to cloud.

The local and cloud paths use the same containerized application boundaries, with infrastructure reviewed as code and deployment separated from permanent hosting.
